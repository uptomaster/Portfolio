## 🧭 About Me

저는 특정 언어나 프레임워크 자체보다  
서비스가 실제로 어떻게 동작하고, 운영되고, 신뢰를 유지하는지에 관심을 두고 프로젝트를 진행해 왔습니다.

웹 서비스 개발을 시작으로 서버 및 데이터베이스 연동,  
리눅스 기반 환경 구성, 네트워크 구조 설계,  
OWASP 기준의 보안 점검까지 경험하며  
단순 기능 구현이 아닌 **운영 관점의 시스템 설계**를 목표로 해왔습니다.

JSP/Servlet 기반 웹 서비스, PHP와 Node.js를 활용한 서비스 구현,  
VM 환경에서의 서버 배포와 운영을 직접 수행했고,  
각 프로젝트마다 왜 이 구조가 필요한지,  
어디에서 문제가 발생할 수 있는지를 중심으로 고민해 왔습니다.
