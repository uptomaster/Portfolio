## 👋 About Me

저는 특정 언어나 프레임워크 자체보다  
**서비스가 실제로 어떻게 동작하고, 운영되고, 신뢰를 유지하는지**에 관심을 두고 프로젝트를 진행해 왔습니다.

웹 서비스 개발을 시작으로  
서버 및 데이터베이스 연동, 리눅스 기반 환경 구성,  
네트워크 구조 설계와 OWASP 기준의 보안 점검까지 경험하며  
단순 기능 구현이 아닌 **운영 관점의 시스템 설계**를 목표로 해왔습니다.

개인 프로젝트에서는 JSP/Servlet 기반 웹 서비스,  
PHP와 Node.js를 활용한 서비스 구현,  
VM 환경에서의 서버 배포와 운영을 직접 수행했고,  
각 프로젝트마다 왜 이 구조가 필요한지,  
어디에서 문제가 발생할 수 있는지를 중심으로 고민해 왔습니다.

최근에는 분실물 서비스 **FindMe**를 기획하며  
QR 인증, 상태 전이, 보상 구조처럼  
사람 간 신뢰를 **시스템적으로 어떻게 강제할 수 있는지**에 집중하고 있습니다.  
이 과정에서 웹보다 모바일 환경이 더 적합하다고 판단해  
안드로이드 네이티브(Android Studio, XML 기반) 프로젝트로 확장해 진행 중입니다.

새로운 기술을 빠르게 나열하기보다  
이미 이해한 개념을 더 큰 환경으로 확장하고,  
**왜 이 기술이 필요한지 설명할 수 있는 엔지니어**로 성장하고자 합니다.

## 🛠 Tech Stack

### Backend / Server
- Java (JSP / Servlet, MVC 기반)
- PHP
- Node.js (Express)
- REST API 설계
- Session / JWT 기반 인증

### Frontend
- HTML, CSS, JavaScript
- 서버 템플릿 기반 화면 구성

### Database
- MySQL / MariaDB
- Oracle DB
- 데이터베이스 설계 및 연동

- Linux (Rocky Linux, Ubuntu)
- VM 기반 서버 운영

### Mobile
- Android Studio
- Android Native (Kotlin/Java + XML)
- Firebase Authentication 연동 경험
