## About Me

저는 특정 언어나 프레임워크를 중심으로 개발하기보다는  
서비스가 실제로 동작하고 운영되는 전체 구조를 이해하는 데 관심을 두고 있습니다.

지금까지 웹 서비스 개발, 서버 및 데이터베이스 연동,  
리눅스 기반 환경 구성, 네트워크 구조 설계,  
그리고 OWASP 기준의 보안 점검까지 경험하며  
단순 구현이 아닌 **운영과 신뢰를 고려한 시스템 설계**를 목표로 프로젝트를 진행해왔습니다.

개인 프로젝트에서는 JSP/Servlet 기반 웹 서비스,  
PHP와 Node.js를 활용한 서비스 구현,  
VM 환경에서의 서버 배포와 운영을 직접 수행했고,  
각 프로젝트마다 왜 이 구조가 필요한지,  
어디에서 문제가 발생할 수 있는지를 고민해 왔습니다.

최근에는 분실물 서비스 FindMe를 기획하며  
QR 인증, 상태 전이, 보상 구조처럼  
사람 간 신뢰를 시스템적으로 어떻게 보장할 수 있는지에 집중하고 있습니다.  
이 과정에서 웹뿐 아니라 모바일 앱 환경이 더 적합하다고 판단해  
안드로이드 네이티브(Android Studio, XML 기반) 프로젝트로 확장해 진행 중입니다.

저는 새로운 기술을 빠르게 나열하기보다  
기존에 이해한 개념을 더 큰 환경으로 확장하고,  
왜 이 기술이 필요한지를 설명할 수 있는 방향으로 성장하고자 합니다.
